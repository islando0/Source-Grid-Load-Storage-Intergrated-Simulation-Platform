# 实验九答辩提纲（建议版）

> 用途：课堂汇报/答辩时按顺序讲，控制在 8–10 分钟；详细推导见 `docs/模型口径.md`，结果见 `docs/计算结果_v1.md`，机器学习见 `docs/机器学习.md`。

## 1. 一句话定位

做一套“源网荷储一体化规划配置仿真平台”：上传源荷气象数据 → 体检与清洗 → 规则调度仿真 → PSO/GWO 优化风光储容量 → 输出经济、消纳、SOC、碳排指标 → 在 Vue3 大屏和报告中展示。

## 2. 题目要求与完成度

| 文档要求 | 当前实现 |

| 仿真计算：年/月/典型日/小时/15 分钟 | 小时级 5832 点规则调度；典型日与月度聚合；15 分钟样例 04 可做聚合演示 |

## 3. 数据体检（先讲“为什么不能直接算”）

教师包共 10 个文件，主输入是 03 和 05：

- **03 小时级源荷气象电价**：5832 行，2026-01-01—08-31，小时级；负荷 40–56 MW，风速 3–9 m/s，GHI 0–900 W/m²；原始电价只有 0.32/0.45/0.85 三档。
- **05 基准运行结果**：5832 行，50/80/20/80 基准；负荷 37.6–79.2 MW，风电 0–39.1 MW，光伏 0–77.6 MW，SOC 0.1–0.95，弃电 0。
- **06 优化参考**：80/120/40/160/70 MW；文档指标 2.85 亿元、弃电 3.5%、绿电 82.3%、友好性 91.2。
- **04 典型日 15 分钟**：96 点，只有光伏和负荷，没有风电；**09 是草稿**，与 06 冲突，不采信。

关键发现：

1. 03 与 05 的负荷、温度、风速对不上，**不能按时间行合并**；它们代表两个场景/两套口径。
2. 03 原始电价与 07 分时模板不一致；主模型采用 07（谷 0.35/平 0.75/峰 1.15/上网 0.35），03 原始电价留作敏感性。
3. 06 的 2.85 亿元/3.5% 弃电/82.3% 绿电，用 03 或 05 复算都对不上；原因是负荷与资源口径不同，因此 06 只作对照，不当精确答案。
4. 只有 1–8 月共 5832 小时，所有“年化”均按 8760/5832 折算，报告必须写“样本年化”。

## 4. 数据分析流程

1. 读取 CSV/Excel，统一列名与时间格式；
2. 时间去重、缺失插值/前后填充、物理范围裁剪（风速、GHI、SOC、负荷）；
3. 风速按切入 3 m/s、额定 11 m/s 折算 CF；光伏按 GHI/900×0.82 折算 CF；
4. 分时电价映射；
5. 描述性统计：均值/极值/分位数、月度曲线、相关性、典型日；
6. 进入仿真/优化，输出指标与图表；
7. 结果落 SQLite，前端读取展示。

Notebook：`notebooks/01_数据体检与场景对比.ipynb` 与 `notebooks/02_机器学习光伏迁移.ipynb`；02 已执行并嵌入图表输出，01 因本机沙箱 ACL 未嵌入输出，在正常 Jupyter 中“Restart & Run All”即可生成。

## 5. 模型口径

决策变量：

```
x = [C_w, C_pv, C_b, E_b]   # 风电 MW、光伏 MW、储能 MW、储能 MWh
```

目标：最小化年化总成本

```
J = 年化投资 + O&M + 购电成本 - 售电收入 + 碳成本
    + λ_cur × 弃电量 + λ_soc × SOC 越界电量 + 末端 SOC 偏差罚
```

关键参数：

- 投资：风 6500 元/kW、光 3500 元/kW、储 1200 元/kWh；
- 折现 8%、25 年，CRF；O&M 1.5%；
- 碳价 80 元/t，碳因子 0.5703 t/MWh；
- 外网 70 MW；储能 2–6 小时；效率 0.92；
- SOC 硬安全 0.10–0.95，软目标 0.30–0.80（越界罚 0.10 元/kWh）；
- 弃电罚 0.05 元/kWh；失负荷按硬约束（主模型 E_ens=0）。

调度规则：风光优先供负荷；富余先充储，再上网，最后弃电；缺额先放储，再购电，最后失负荷；谷段允许电网充电至 SOC 0.80；日/周期末 SOC 偏差加罚。

## 6. 算法

- **PSO**：种群 12–30，迭代 8–30；速度/位置更新，容量边界投影，储能 2–6 h 修复。
- **GWO**：灰狼分层（α/β/δ），同样 repair。
- 单次 5832 小时仿真约 20 ms；30×30 约 20 分钟，在线默认 12×8 约数秒。
- 结果写 `data/output/*.json` 和 SQLite `runs` 表；NSGA-II Pareto、LP 下界未做，作为后续加分项。

## 7. 结果（场景 A，03）

| 方案 | 风/光/储/储容 | 年化成本 | 弃电率 | 绿电占比 | SOC 30–80 |
|---|---|---:|---:|---:|---:|
| 基线 | 50/80/20/80 | 21,340 万元 | 0.00% | 53.2% | 52.8% |
| PSO 经济最优 | 87.7/167.7/0/0 | 16,802 万元 | 3.86% | 65.7% | 不适用 |
| GWO | 87.6/167.4/0.67/2.94 | 16,815 万元 | 3.81% | — | 41.3% |
| 06 参考配置 | 80/120/40/160 | 18,759 万元 | 0.03% | — | 43.8% |

结论：成本优先时零储能是经济最优，因为外网 70 MW 能保供、储能 capex 高、弃电多为长时段富余，日调节储能吃不下。但零储能无法体现“最佳储能范围 30%–80%”，所以答辩建议给两个方案：

- **经济最优**：回答“为什么不配储”；
- **友好配置 80/120/40/160**：弃电从 3.86% 降到 0.03%，年化多约 1,957 万元，作为推荐方案。

如果老师要求严格证明“带储能最优”，需要增加最低配储、绿电占比或弃电率上限约束后重算；当前版本尚未加这些约束，不能把 06 的结果当成模型输出。

## 8. 机器学习（外部数据 → 03）

要求：选用网络数据集训练机器学习，再用它分析教师数据。

- 外部数据：Kaggle **Solar Power Generation Data**（Plant 1，33 天，15 分钟级，3,157 个聚合点）。
- 模型：随机森林回归；输入辐照度、气温、时刻 sin/cos；目标为 `AC_POWER/30MW` 容量因子。
- 切分：按日期前 80% 训练、后 20% 测试；外部测试集 MAE 0.0077、R² 0.9964。
- 迁移：把 03 的 GHI、温度输入模型，得到 ML CF；与物理 `GHI/1000×0.82` 对比，均值 0.269 vs 0.234，相关系数 0.9997。
- 仿真：基准 50/80/20/80，年化成本 2.134 → 1.964 亿元（−7.95%），LCOE 0.503 → 0.463，绿电 53.2% → 55.8%，弃电均为 0。
- 边界：外部数据仅 33 天、位于印度，存在域偏移；ML 仅作对照，物理口径仍是主结果。

演示：打开“机器学习”页，讲模型来源、测试指标、典型日物理/ML 曲线、误差分布、两个口径的仿真对比。

## 10. 可能被问的问题

**Q1：为什么最优是零储能？是不是模型错了？**
不是。外网 70 MW 保供、储能投资高、弃电是长时段富余，规则调度下储能收益有限。把“储能 30–80%”当软目标、成本优先，就会得到零储能；若老师要求必须配储，需要加约束而不是改结果。

**Q2：为什么 06 的 2.85 亿元对不上？**
06 的负荷/资源/成本口径与 03、05 不一致；本模型统一用 03 的负荷和资源、07 的电价、08 的成本，所以只能把 06 当参考，不能当精确答案。

**Q3：只有 8 个月，怎么算年化？**
按 8760/5832 折算投资、购电、弃电等，报告标注“样本年化”；不把 8 个月说成全年实测。

**Q4：15 分钟数据怎么处理？**
04 是 96 点典型日样例，只有光伏和负荷；平台主链路是小时级 5832 点。15 分钟数据可聚合到小时，或作为典型日展示；当前没有做 15 分钟全时序优化。

**Q5：PSO 和 GWO 哪个好？**
本问题两者接近；PSO 更快、结果稳定，GWO 在零储能边界附近容易产生不可行解，已用 repair 修复。答辩以 PSO 为主，GWO 作交叉验证。

**Q6：机器学习在哪里？**
已接入，不是预留接口。用 Kaggle 公开光伏数据训练随机森林 CF 模型（外部测试 R² 0.996），再迁移到 03 的 GHI/温度；前端“机器学习”页展示模型来源、测试指标、迁移曲线、误差分布和仿真对比。外部数据只有 33 天且存在域偏移，因此 ML 作为对照，物理口径仍是主结果。
