# 模型口径（v1，2026-10-20）

> 依据：`实验9.docx`、数据包 01–10、老师最新要求（核心是计算；满足负荷下减少弃风弃光；最小化成本；SOC 30%–80% 为偏好；推荐 PSO/GWO）。
> 本文件是后续仿真器、算法、后端和报告的**唯一模型口径**；与 v3 方案冲突时，以本文件为准。

## 2. 决策变量

```
x = [C_w, C_pv, C_b, E_b]
```

| 变量 | 含义 | 单位 | 边界 |
|---|---|---|---|
| `C_w` | 风电装机 | MW | 0–300 |
| `C_pv` | 光伏装机 | MW | 0–300 |
| `C_b` | 储能功率 | MW | 0–150 |
| `E_b` | 储能容量 | MWh | 0–600 |

附加约束：`2·C_b ≤ E_b ≤ 6·C_b`；外网容量暂定 70 MW（固定，不参与优化）。

## 3. 目标函数

**主目标：年化总成本最小。** 弃风弃光作为小权重惩罚（成本优先），负荷满足作为硬约束。

```
min J = C_ann + C_om
        + Σ price_buy·g_in·Δt - Σ price_sell·g_out·Δt
        + C_carbon
        + λ_cur·E_curt
        + λ_soc·E_soc_out
        + λ_ens·E_ens
```

| 项 | 口径 |
|---|---|
| `C_ann` | 年化投资：`CRF × CAPEX`，`CRF = r(1+r)^N / ((1+r)^N-1)`，r=8%，N=25 |
| `C_om` | 年运维：按 CAPEX 的 1.5%（08 未给，作可配置假设） |
| `CAPEX` | `6500×1000×C_w + 3500×1000×C_pv + 1200×1000×E_b`（元） |
| `price_buy/sell` | 优先用 07 分时模板；03 原始电价做敏感性 |
| `C_carbon` | `EF × 购电量 × 80 元/t`，EF 默认 0.5703 tCO2/MWh，可配置 |
| `λ_cur` | 0.05 元/kWh（小权重，仅用于打破“同成本多解”的平局） |
| `λ_soc` | 0.10 元/kWh（30%–80% 软目标越界惩罚） |
| `λ_ens` | 失负荷罚函数；主模型按硬约束 `E_ens = 0` 处理 |

**成本优先的含义**：不设弃电率硬上限；先保证成本最低，弃电只做小权重和结果展示。若成本相同的方案，选弃电更小的。

**多目标仅作分析**：`[年化总成本, 弃风弃光率]` 的 Pareto 前沿用于报告，不作为主结果。主结果取成本最低点。

## 4. 约束

1. 逐时功率平衡：

```
C_w·wind_cf[t] - cur_w[t] + C_pv·pv_cf[t] - cur_pv[t]
+ dis[t] - ch[t] + g_in[t] - g_out[t] + ens[t] = load[t]
```

2. SOC 硬安全边界：`0.10 ≤ SOC_t ≤ 0.95`。
3. SOC 软目标：`0.30 ≤ SOC_t ≤ 0.80`；越界计入 `E_soc_out`，不强制停运。
4. SOC 递推：

```
e[t+1] = e[t] + η_c·ch[t]·Δt - dis[t]·Δt/η_d
SOC_t = e[t] / E_b
```

5. 初始 SOC 0.55；日/周期首末闭合（`e[0] = e[T]`）。
6. 充放功率：`0 ≤ ch[t] ≤ C_b`，`0 ≤ dis[t] ≤ C_b`。
7. 外网：`0 ≤ g_in[t] ≤ 70 MW`；`0 ≤ g_out[t] ≤ 70 MW`（可配置）。
8. 负荷满足：`E_ens = 0`（主模型硬约束）；若不可行，允许极小 `E_ens` 并高罚。
9. 弃电上限：`cur_w[t] ≤ C_w·wind_cf[t]`，`cur_pv[t] ≤ C_pv·pv_cf[t]`。
10. 储能时长：`2·C_b ≤ E_b ≤ 6·C_b`。

## 5. 调度规则（仿真器）

对每个时刻：

1. 风光可用出力。
2. 优先满足负荷。
3. 富余：先充储能（SOC < 0.95，考虑效率），再按外网容量上网，最后弃电。
4. 缺额：先放储能（SOC > 0.10），再购电（≤70 MW），最后记失负荷。
5. 谷段可适当从电网充电，峰段优先放电；实现为：谷价（≤0.40 元/kWh）时电网先供负荷，剩余外网容量给储能充电至 SOC 0.80；不强制日循环次数。
6. 记录 `wind_used/pv_used/battery/grid_buy/grid_sell/soc/curtail/ens`。

## 6. 算法

| 算法 | 库 | 用途 |
|---|---|---|
| PSO | `src/optimize.py`（自实现，可换 MEALPY） | 主算法：单目标最小年化成本 |
| GWO | `src/optimize.py`（自实现，可换 MEALPY） | 与 PSO 对比 |
| NSGA-II | pymoo（待接） | 成本-弃电 Pareto（分析） |
| LP / HiGHS | SciPy（待接） | 线性化下界，验证启发式 |

- 粒子/狼群：30–50；迭代 100–200；边界见第 2 节。
- 约束处理：负荷/SOC 硬边界用罚函数；容量边界用裁剪；`2C_b≤E_b≤6C_b` 用 `repair()` 投影。
- 评估：每个候选跑 5832 小时；当前纯 Python/NumPy 约 20 ms/次；先用小种群筛选，最优解全时序复核。
- 结果：收敛曲线、最优容量、成本、弃电率、SOC 30%–80% 占比、越界电量。

## 7. 指标

| 指标 | 口径 |
|---|---|
| 年化总成本 | 目标函数主项 |
| LCOE | 年化总成本 / 年供电量 |
| 弃风弃光率 | 弃电量 / 可发电量 |
| 新能源消纳率 | 1 - 弃电率 |
| 绿电占比 | 1 - 外购电量/用电量 |
| 失负荷率 | EENS / 用电量（主模型应为 0） |
| SOC 30%–80% 占比 | 处于软区间的小时数 / 总小时数 |
| SOC 越界电量 | 软区间外的能量积分 |
| 碳减排 | 基准排放 - 实际排放 |
| 友好性评分 | 源/网/荷/经济/低碳五维 |

## 8. 关键假设（报告必须写）

- 8 个月数据；年化指标按 5832 小时折算，不冒充全年 8760。
- 年化投资按 25 年、8% 折现；O&M 1.5% 为假设。
- 碳因子 0.5703 tCO2/MWh 为默认值，可配置。
- 电价优先用 07 模板；03 原始电价为敏感性。
- 外网 70 MW 固定；不优化外网容量。
- 储能效率 0.92；SOC 硬边界 10%–95%，软目标 30%–80%。
- 规则调度非全局最优；LP 仅作线性化下界。

**基线（场景 A，50/80/20/80）**
- 年化总成本 21340.1 万元，LCOE 0.503 元/kWh，弃电率 0，绿电占比 0.532，SOC 软区间占比 0.528，末期 SOC 0.10。

**优化主结果（场景 A，30 粒子/狼 × 30 代，seed=3）**
- PSO：`x=[87.68, 167.70, 0, 0]`，年化 16802.1 万元，弃电率 3.86%，绿电占比 65.7%，零储能。
- GWO：`x=[87.61, 167.40, 0.67, 2.94]`，年化 16815.4 万元，弃电率 3.81%，SOC 软区间 41.3%。
- **关键发现**：按“成本优先 + λ_soc=0.10 + λ_cur=0.05”的现口径，零储能是经济最优；储能 40 MW/160 MWh 年化 18759.1 万元，更贵。原因：外网 70 MW 足以保供，储能不能显著降低弃电，且投资/运维高。
- **待确认**：是否把“储能必须配置/最低容量”“绿电占比”“弃电率上限”作为约束；否则主结果如实报告“零储能经济最优”，把 40/160 作为政策/低碳情景对照。

**机器学习迁移（外部 Kaggle 光伏数据 → 03）**
- 外部数据 3,157 个 15 分钟聚合点；随机森林测试集 MAE 0.0077、R² 0.9964。
- 03 上 ML CF 均值 0.2688，物理 CF 均值 0.2336，相关系数 0.9997，MAE 0.0352。
- 基准方案：年化成本 21,340.1 → 19,643.4 万元（−7.95%），LCOE 0.503 → 0.463 元/kWh，绿电占比 53.2% → 55.8%，弃电率均 0。
- 解释边界：外部数据仅 33 天、位于印度，存在域偏移；ML 只作对照，物理口径仍是主结果。
